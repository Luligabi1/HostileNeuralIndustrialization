# Мультиблоки

Ваше производство можно улучшить мультиблочными версиями предыдущих машин: [Большая симуляционная камера](./multiblock/large_sim_chamber.md) и [Большой производитель добычи](./multiblock/large_loot_fabricator.md).

Перед началом следует убедиться, что у вас есть:
- 
- Самодостаточная линия по производству **нержавеющей стали**;
- Много **матриц предвычислений** для изготовления **корпусов предвычислительной машины**. Их можно автоматизировать через сборщик;
- Доступ к **усовершенствованным двигателям**.
